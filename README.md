### hey, i'm pepe.

I started out with low-voltage systems. Somewhere along the way, they turned into pull requests.

I'm an **AI/ML engineer**, currently building **agentic AI products on AWS**. I like working with people, testing whether an idea actually works, and improving the small details that usually get ignored.

<sub>Currently based in Spain. Usually listening to something.</sub>

---

### 01 / things i've built

| Project | A few words |
| :-- | :-- |
| [**local-llm-bench-lab**](https://github.com/pepe-va/local-llm-bench-lab) | Reproducible `llama.cpp` benchmarks, built with small hardware in mind. Speed, memory, quality, and less guessing. |
| [**ibex35-rag**](https://github.com/pepe-va/ibex35-rag) | A local RAG system for asking questions about IBEX 35 financial reports, with hybrid search and observability. |
| [**vision-language-object-detection**](https://github.com/pepe-va/vision-language-object-detection) | Finding objects from natural-language prompts using SAM and CLIP, entirely on-device. |
| [**gpu-ml-benchmarking-rapids-vs-spark**](https://github.com/pepe-va/gpu-ml-benchmarking-rapids-vs-spark) | Comparing GPU-accelerated RAPIDS cuML and Spark ML pipelines on the same classification task. |

Some of the code is public. The experiments don't always behave.
